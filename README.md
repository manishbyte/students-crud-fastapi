# Students Database CRUD Application

Python backend internship project using **FastAPI** and **SQLite**. The optional Ollama/AI extension is intentionally excluded.

## Features

- Create, list, retrieve, update, and delete student records
- SQLite persistence (data remains after restarting the server)
- Input validation with Pydantic
- Filter students by partial name, course, and date of birth
- Pagination with `limit` and `offset`
- Clear `404` responses when a student does not exist
- Interactive Swagger API documentation

## Student fields

- `student_id`: unique ID generated by SQLite
- `name`: required
- `date_of_birth`: required, ISO format `YYYY-MM-DD`
- `email` and/or `phone`: at least one is required
- `course`, `address`, `enrollment_date`: optional

## Requirements

- Python 3.10 or newer
- pip

## Setup

### Windows (PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
uvicorn app.main:app --reload
```

If PowerShell blocks activation, use Command Prompt:

```bat
.venv\Scripts\activate.bat
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000/docs for Swagger UI. The SQLite database `students.db` is created automatically at startup.

## API endpoints

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/students` | Create a student |
| `GET` | `/students` | List/filter students |
| `GET` | `/students/{student_id}` | Get one student |
| `PUT` | `/students/{student_id}` | Replace all editable student fields |
| `PATCH` | `/students/{student_id}` | Update selected fields |
| `DELETE` | `/students/{student_id}` | Delete a student |
| `GET` | `/health` | Health check |

## Example requests

### Create a student

```bash
curl -X POST "http://127.0.0.1:8000/students" ^
  -H "Content-Type: application/json" ^
  -d "{\"name\":\"Aarav Patil\",\"date_of_birth\":\"2005-08-12\",\"email\":\"aarav@example.com\",\"course\":\"Computer Engineering\",\"address\":\"Pune\"}"
```

On Windows PowerShell, `curl` may be an alias. You can instead use Swagger UI at `/docs` or `Invoke-RestMethod`.

JSON body:

```json
{
  "name": "Aarav Patil",
  "date_of_birth": "2005-08-12",
  "email": "aarav@example.com",
  "phone": "9876543210",
  "course": "Computer Engineering",
  "address": "Pune",
  "enrollment_date": "2026-10-14"
}
```

### List all students

```http
GET /students
```

### Filter students

```http
GET /students?name=aarav
GET /students?course=Computer%20Engineering
GET /students?born_after=2005-01-01
GET /students?limit=20&offset=0
```

### Get one student

```http
GET /students/1
```

### Update selected fields

```http
PATCH /students/1
Content-Type: application/json

{
  "course": "Information Technology"
}
```

### Replace a record

Send a complete valid student object to `PUT /students/1`.

### Delete a record

```http
DELETE /students/1
```

Successful deletion returns `204 No Content`. Unknown student IDs return `404 Not Found`.

## Validation and safety

- Names and dates of birth are required.
- Provide an email address, phone number, or both.
- Email format and field lengths are validated.
- Use sample/dummy student data only; do not commit real student personal information.
- The SQLite database file is excluded from Git by `.gitignore`.
